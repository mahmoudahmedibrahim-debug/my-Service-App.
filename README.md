# شطبلي (Shatably)

تطبيق ماركت بليس لطلب خدمات منزلية محلية (سباكة، نجارة، كهرباء، نقاشة، نقل عفش، تنظيف، غسيل سيارات، دليفري، حلاقة...) في مدينة الإسماعيلية، مبني بمنطق العروض التنافسية (Bidding) على نمط InDrive.

المشروع ده مبني من متطلبات الفريق المؤسس (محمود، هيثم، مهند، معتصم، عبدالرحمن) زي ما اتفق عليها في نقاشات الجروب وكراسة الـ SOW النهائية.

## بنية الريبو

```
mobile_app/   تطبيق Flutter كامل (Android + iOS + Web)
docs/         كراسة نطاق العمل (SOW) بالعربي والإنجليزي
```

## تشغيل التطبيق محليًا

```bash
cd mobile_app
flutter pub get
flutter run            # على جهاز/إيميوليتور متصل
flutter run -d chrome   # تجربة سريعة في المتصفح
```

التطبيق شغّال بالكامل بـ **بيانات تجريبية محلية (Mock Backend)** داخل `lib/state/app_state.dart` — يعني تقدر تجرب كل السيناريوهات (تسجيل عميل/مقدم خدمة، طلب خدمة، عروض، دفع، تقييم، شكاوى، لوحة الإدارة) من غير ما تحتاج تربط سيرفر حقيقي. رقم `01000000000` بيدخلك كـ Admin تجريبيًا.

## الحالة الحالية والخطوات الجاية

- ✅ الكود اتكتب بالكامل: كل الشاشات والـ flows المتفقة عليها في الـ SOW (تسجيل الطرفين، توثيق مقدم الخدمة، نظام العروض، السعر العادل، العمولة 15%/12%، التقييم الإجباري، الشكاوى، لوحة الإدارة).
- ✅ `flutter analyze` و`flutter test` بيعدّوا من غير أي مشاكل.
- ✅ `flutter build web --release` بينجح بالكامل — دليل إن الكود يتبني صح من الألف للياء.
- ⚠️ **مبنيش APK حقيقي في السيشن دي** لأن بيئة التشغيل السحابية ماعندهاش صلاحية تحميل Android SDK (سياسة شبكة الأمان بتمنع الوصول لـ `dl.google.com`). عشان تطلع نسخة APK/AAB جاهزة لجوجل بلاي، شغّل على جهازك (أو على CI زي GitHub Actions/Codemagic):

  ```bash
  cd mobile_app
  flutter build appbundle --release   # الصيغة المطلوبة لجوجل بلاي (.aab)
  # أو
  flutter build apk --release         # لو عايز APK للتجربة المباشرة
  ```

  الناتج هيبقى في `mobile_app/build/app/outputs/`.

## قبل ما تطرحه على جوجل بلاي فعليًا

1. **ربط باك اند حقيقي**: استبدال `AppState` (المحاكاة المحلية) بـ Firebase (Auth + Firestore + Storage) أو API مخصص — البنية متصممة عشان الاستبدال ده يبقى في ملف واحد بس.
2. **نظام دفع حقيقي**: ربط بوابة دفع (Paymob / Fawry / Stripe...) بدل شاشة الدفع التجريبية.
3. **Signing key**: عمل keystore خاص بيك وربطه بـ `android/app/build.gradle` قبل build الـ release.
4. **حساب Google Play Console** (رسوم تسجيل مرة واحدة) + Privacy Policy URL + لقطات شاشة + وصف التطبيق.
5. **مراجعة قانونية** لبند الوساطة/الضرائب المذكور في نقاش الفريق (عمولة وسيط مقابل مقدم خدمة، VAT).
